## 🚀 طريقة التثبيت

### الخيار 1: بدون Backend (يعمل مباشرة)
افتح `index.html` في المتصفح ← يعمل فوراً بـ LocalStorage!

### الخيار 2: مع MySQL (للاستخدام الحقيقي)

**1. تثبيت الخادم:**
- XAMPP أو WAMP أو LAMP

**2. إعداد قاعدة البيانات:**
```sql
-- افتح phpMyAdmin ثم نفذ:
SOURCE /path/to/database.sql;
```

**3. تعديل db.php:**
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');      // ← اسم المستخدم
define('DB_PASS', '');           // ← كلمة المرور
define('DB_NAME', 'pos_system');
```

**4. رفع الملفات:**
```
htdocs/pos/
├── index.html
├── style.css
├── app.js
├── ...
```

**5. فتح المتصفح:**
```
http://localhost/pos/
```
